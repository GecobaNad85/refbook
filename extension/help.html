CNKI 工具书划词查询

在任意网页选中文字或点击浮动图标，即时查询 CNKI工具书总库 中的词条释义。支持智能分词、全文展开、可拖动图标。

Chrome MV3 扩展 CNKI工具书总库 SegmentIt 智能分词 CDN 按需加载

功能介绍

划词即查

选中任意网页文字，自动弹出浮窗显示工具书释义，无需复制粘贴。

图标入口

页面右下角浮动图标，点击输入词语查询，适合无法划选的场景。

可拖动图标

浮动图标支持鼠标/触摸拖动，松手后位置自动记忆并恢复。

全文展开

首条结果自动获取完整释文，支持展开/收起，也可手动获取全文。

来源跳转

每条结果标注工具书来源，点击书名直接跳转 CNKI 原文页面。

智能缓存

查询结果 5 分钟缓存、全文 30 分钟缓存，减少重复请求。

智能分词查询NEW

整词无结果时自动用 SegmentIt 分词，多标签展示各子词结果，默认定位首个有内容的标签。

在线分词引擎

通过 CDN 加载 SegmentIt 中文分词库（含完整词典），按需加载不占用扩展体积，加载后缓存在内存中。

多标签切换

分词结果以标签页形式展示，各标签独立支持全文获取与来源跳转。

下载与安装

1
获取扩展文件
将 extension 整个文件夹下载或克隆到本地任意目录。
2
打开扩展管理页
在 Chrome 地址栏输入 chrome://extensions 并回车。
3
开启开发者模式
页面右上角打开「开发者模式」开关。
4
加载已解压的扩展程序
点击左上角「加载已解压的扩展程序」，选择本地的 extension 文件夹。
5
安装完成
扩展列表中出现「CNKI 工具书划词查询」即安装成功，刷新任意网页即可使用。
修改 background.js 后需在扩展管理页点击「Service Worker」旁的刷新按钮；修改 content.js 或 popup.css 后刷新当前网页即可生效。

使用方式

方式一 划词查询
  1. 在任意网页中用鼠标选中想要查询的词语或短语。
  2. 松开鼠标后，选中位置附近自动弹出查询结果浮窗，展示匹配的工具书词条。
  3. 首条结果会自动获取完整释文（异步加载，稍候即展开）。
  4. 点击「查看全文」按钮可手动获取首条结果的完整内容。
  5. 点击底部「在CNKI工具书总库查看更多释义 →」跳转到搜索页。
  6. 按 Esc 或点击浮窗外部区域可关闭弹窗。

方式二 图标入口查询
  1. 网页右下角有一个蓝色放大镜浮动图标 ，点击打开搜索面板。
  2. 在输入框中输入要查询的词语。
  3. 按 Enter 回车键或点击「查询」按钮提交。
  4. 结果区显示匹配的工具书词条，同样支持「查看全文」和来源跳转。
  5. 点击右上角「×」、按 Esc 或点击面板外部可关闭。
技巧 拖动浮动图标
  1. 用鼠标按住浮动图标不放。
  2. 拖动到屏幕中任意位置（图标会自动限制在视口范围内）。
  3. 松开鼠标，图标位置自动保存，下次打开网页时自动恢复到上次位置。
  4. 轻微点击（未拖动）仍会打开搜索面板，不会误触发拖动。
提示：触摸屏设备同样支持按住拖动。
新功能 智能分词查询（自动多标签）
  1. 选中较长文本（如「西藏日喀则市」）进行划词查询。
  2. 若整词在 CNKI工具书总库 中无结果，扩展会自动使用 SegmentIt 分词引擎对文本进行智能分词。
  3. 分词后并行查询各子词（如「西藏」「日喀则市」），有结果的子词以标签页形式展示。
  4. 弹窗默认自动定位到第一个有内容的标签，无需手动翻找。
  5. 点击顶部标签栏可在各分词结果之间切换，每个标签独立支持「查看全文」与来源跳转。

进阶 获取完整释文（全文）
  1. 完整释文（全文）需要 CNKI 登录凭证，首次使用请先访问 gongjushu.cnki.net 并登录。
  2. 登录后扩展会自动捕获认证凭证，之后的查询即可自动获取词条全文。
  3. 若全文未加载，点击结果中的「查看全文」按钮可手动重试。
  4. 凭证过期时，重新访问 gongjushu.cnki.net 登录即可恢复。

常见问题

Q全文/完整释文加载失败怎么办？
完整释文需要 CNKI 登录态。请先访问 gongjushu.cnki.net 并登录，登录后扩展会自动获取凭证。之后重新划词或查询即可加载全文。
Q浮动图标位置不合适怎么办？
直接用鼠标按住图标拖动到合适的位置即可，位置会自动记忆。如需重置，可拖回右下角附近。
Q分词查询是如何工作的？
选中长文本查询无结果时，扩展通过 CDN 加载 SegmentIt 中文分词库对文本进行智能切分（如"西藏日喀则市"→"西藏"+"日喀则市"），然后并行查询各子词，有结果的子词以标签页形式展示。分词库按需从 jsDelivr CDN 加载，加载后缓存在内存中。若网络不可用则自动回退到滑动窗口分词。
Q在某些网页上划词没有反应？
部分网站（如 Chrome 内置页面 chrome:// 页面、应用商店页面）不允许内容脚本注入，这是 Chrome 的安全限制，属正常现象。请在普通网页上使用。
Q点击工具栏图标有什么作用？
点击浏览器右上角的扩展工具栏图标，会在新标签页打开本说明页面。
Q查询结果中的摘要和全文有什么区别？
摘要是搜索接口返回的词条片段（通常较短），全文是条目详情接口返回的完整释文内容。两者数据均来自 CNKI工具书总库，全文需要登录态才能获取。
